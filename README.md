## 🚀 Getting Started

### 1) Clone

```bash
git clone https://github.com/SCodreanu/SCodreanu-Portfolio.git
cd SCodreanu-Portfolio
```

### 2) Install

```bash
npm install
```

### 3) Run locally

```bash
npm run dev
```

### 4) Build

```bash
npm run build
```
